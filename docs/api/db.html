Database Layer (fairwddi.db)

The fairwddi.db package contains configuration utilities, raw DDL exporters, SKOS vocabulary importers, and fixture seeders.

Configuration & Environment

Database configuration and environment resolver for FAIRwDDI.

Supports .env files, DATABASE_URL strings, and discrete PostgreSQL / SQLite environment variables.

fairwddi.db.config.configure_django_for_cli()[source]

Initialize Django runtime with resolved settings for CLI and standalone use.

fairwddi.db.config.get_database_config()[source]

Resolve database configuration from environment variables (.env / system).

Resolution priority: 1. DATABASE_URL (e.g. postgresql://user:pass@localhost:5432/fairwddi_db) 2. Discrete PostgreSQL vars (POSTGRES_DB / DB_NAME, POSTGRES_USER, POSTGRES_HOST, etc.) 3. SQLite file path (FAIRWDDI_DB_PATH or default ‘./fairwddi_dev.sqlite3’)

fairwddi.db.config.load_dotenv_config(env_path=None)[source]

Load environment variables from a .env file if available.

fairwddi.db.config.parse_database_url(url)[source]

Parse a DATABASE_URL into Django DATABASES configuration dictionary.

DDL Generation

DDL generator and export utility for PostgreSQL >= 17.

fairwddi.db.ddl.export_postgres_ddl(output_path=None)[source]

Export PostgreSQL DDL to a destination file path or return the SQL string.

fairwddi.db.ddl.generate_ddl_sql()[source]

Read and return the raw PostgreSQL DDL SQL string.

fairwddi.db.ddl.get_sql_ddl_path()[source]

Return the absolute path to the bundled postgres_init.sql script.

Vocabulary Importers

Generic SKOS / XKOS controlled vocabulary loader and inspector for FAIRwDDI.

Supports standard-agnostic ingestion of any SKOS / SKOS-XL / XKOS RDF vocabulary in Turtle (.ttl), RDF/XML (.rdf, .xml), JSON-LD (.jsonld, .json), N-Triples (.nt), and Notation3 (.n3) formats (e.g., CESSDA ELSST, CESSDA Topics, DDI-CV, UNESCO, Eurostat RAMON, Agrovoc, STW, custom project taxonomies).

fairwddi.db.vocab.check_vocabulary_loaded(vocabulary=None)[source]

Check if concepts for a given vocabulary (or any vocabularies) are loaded.

Returns status summary dictionary.

fairwddi.db.vocab.extract_urn(subject, graph, fallback_prefix='concept', default_agency='fr.cdsp')[source]

Extract authoritative/original URN from RDF node, or synthesize fallback DDI URN.

Priority: 1. If the subject URI itself starts with ‘urn:’, use it directly. 2. Search dct:identifier, dc:identifier, and skos:notation for values starting with ‘urn:’. 3. Fallback: synthesize ‘urn:ddi:{agency}:{fallback_prefix}-{id}:1.0.0’.

fairwddi.db.vocab.load_elsst_vocabulary(file_path, max_levels=None, reload=False, vocabulary_name=None, rdf_format=None)

Load any SKOS / XKOS vocabulary into the Concept table from an RDF file.

Parameters: - file_path: Path to the RDF file (.ttl, .rdf, .xml, .jsonld, .nt, etc.). - max_levels: Optional depth limit (1 for top concepts, 2 for top + level 1, None for all). - reload: If True, clears existing concepts for this vocabulary before loading. - vocabulary_name: Name of vocabulary (if None, infers from scheme or file stem). - rdf_format: RDF format (if None, auto-detected from file extension).

Returns summary dictionary.

fairwddi.db.vocab.load_skos_vocabulary(file_path, max_levels=None, reload=False, vocabulary_name=None, rdf_format=None)[source]

Load any SKOS / XKOS vocabulary into the Concept table from an RDF file.

Parameters: - file_path: Path to the RDF file (.ttl, .rdf, .xml, .jsonld, .nt, etc.). - max_levels: Optional depth limit (1 for top concepts, 2 for top + level 1, None for all). - reload: If True, clears existing concepts for this vocabulary before loading. - vocabulary_name: Name of vocabulary (if None, infers from scheme or file stem). - rdf_format: RDF format (if None, auto-detected from file extension).

Returns summary dictionary.

Seed & Fixture Management

Database seeder for FAIRwDDI.

Populates the database with multilingual DDI model sample data (DDI 4 / DDI-CDI / DDI-L 3.3) across all architectural layers using standard canonical DDI 3.3 / 4.0 URNs.

fairwddi.db.seed.seed_sample_data(reset=False)[source]

Seed the database with standard DDI model demonstration entities.

If reset is True, clears existing records first. Returns a summary dictionary of created entity counts.

Wipe Utilities

Database wipe utility for FAIRwDDI.

Deletes all records across all FAIRwDDI tables in safe reverse topological order.

fairwddi.db.wipe.wipe_database()[source]

Wipe all records across all FAIRwDDI tables in reverse topological order.

Returns a summary dictionary of deleted record counts by entity.
