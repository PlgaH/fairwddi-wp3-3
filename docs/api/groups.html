Group Curation & Set Resolution (fairwddi.groups)

DDI Group & VariableGroup curation manager (fairwddi.groups.manager).

Provides CRUD and membership management for reusable context groups (longitudinal series, thematic variable clusters, question grids, comparison scopes). Groups carry both a canonical DDI URN and an optional unique human-friendly slug, and keep their JSONB references list synchronized with dcterms:isPartOf SemanticRelationship triples.

Unified Resource Set Resolver (fairwddi.groups.resolver).

Resolves structured set specifiers into typed URN sets for downstream comparison and harmonization workflows:

  • group:<slug_or_urn> — expands StudyUnits to full variable cascades & traverses nested groups

  • batch:<id> — resources created by a specific IngestBatch

  • study:<urn> — single StudyUnit + full cascade (Datafile, InstanceVariable, RepresentedVariable, QuestionItem, CodeList, Category, ConceptualVariable, Concept)

  • bank / bank:all / bank:imported / bank:harmonized — bank slices by origin

  • urn:<u1,u2,...> — explicit list of resource URNs
