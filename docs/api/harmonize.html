Comparison-driven Harmonization Planner (fairwddi.harmonize.planner).

Consumes a ComparisonResultSet (or *.comparison.yaml/.json) and applies a HarmonizationPolicy to emit a review-gated HarmonizationPlan. Supports --approve-high / approve_high=True using explicit thresholds and allowlists defined in HarmonizationPolicy.auto_approve_high.

fairwddi.harmonize.planner.approve_high_actions(plan_or_path, *, policy=None, high_threshold=None, output_path=None)[source]

Retroactively mark eligible high-confidence actions as approved on an existing plan.

fairwddi.harmonize.planner.plan_harmonization(comparison, policy=None, *, approve_high=False, high_threshold=None, keep_pending=False, output_dir=None)[source]

Translate a comparison result set into a review-gated HarmonizationPlan.

Parameters:

  • comparison (ComparisonResultSet | Path | str) – In-memory ComparisonResultSet or path to *.comparison.yaml/.json.

  • policy (str | Path | HarmonizationPolicy | None) – HarmonizationPolicy, preset name (default), or YAML file path.

  • approve_high (bool) – When True (and keep_pending is False), immediately approve actions satisfying policy.auto_approve_high criteria.

  • high_threshold (float | None) – Optional override for policy.auto_approve_high.min_confidence.

  • keep_pending (bool) – Explicitly suppress auto-approval so all actions remain pending review.

  • output_dir (str | Path | None) – Optional directory to write *.harmonize.plan.yaml and .report.md.

Comparison-driven Harmonization Execution & Lineage Manager (fairwddi.harmonize.manager).

Supports:

  • Linking imported resources into existing generated or instantiated resources (link_to_harmonized_resource) while enriching metadata (alternate spellings, languages).

  • Creating new generated or instantiated harmonized resources from imported resources (create_harmonized_resource).

  • Declarative shared-stem grouping (Group with dcterms:isPartOf).

  • Explicit W3C PROV-O / SKOS lineage (prov:wasDerivedFrom, skos:closeMatch, skos:relatedMatch) with correspondence_level, match_type, confidence, and codelist_qualification metadata.

  • Transactional rollback (undo_harmonization) via EventLog snapshots.
