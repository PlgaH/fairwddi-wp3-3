Database Comparison

Stage 3a (Comparison & Discovery): Cross-survey candidate discovery and similarity comparison.

Evaluates ReQuest resources (Category, CodeList, QuestionItem, RepresentedVariable) across tiers delegating string algorithms, stem detection, and variant classification to dartfx.ddi.harmonizer:

  1. EXACT (1.00): Identical content hash.

  2. FACET_EXACT (0.95): Identical normalized label or question_text hash across present languages.

  3. MULTILINGUAL_OVERLAP (0.92): Exact match in at least one shared language with complementary translations, or complementary language labels on matching code structures.

  4. NEAR_EXACT (0.96 - 0.98): Identical after loose punctuation normalization or >= 0.98 similarity.

  5. INCLUSIVE_WRITING_VARIANT (0.98): Identical after stripping inclusive gender/plural markers.

  6. TYPOGRAPHICAL_VARIANT (0.95): Single-word typographical or grammatical error variant.

  7. PHRASING_VARIANT (0.92 - 0.94): Stylistic or pronominal phrasing variation.

  8. SHARED_STEM / SHARED_STEM_GRID (0.88): Shared prompt or stem with distinct sub-items.

  9. SAME_CONCEPT_DIVERGENT_DOMAIN / SAME_CONCEPT_DIFFERENT_SCALE (0.88): Equivalent concept/label with divergent CodeLists. Action downgraded to link_semantic.

  10. SUBSTANTIVE_PERMUTATION (0.88): CodeLists sharing identical substantive categories.

  11. CATEGORIES_EXACT_CODES_DIFFERENT (0.85): CodeLists with identical categories, different codes.

  12. SYNTACTIC_SIMILAR (0.75 - 0.91): General normalized string similarity on label/question_text.

fairwddi.ingest.loader.undo_ingestion(batch_id)[source]

Roll back an IngestBatch in a single atomic transaction.

Deletes UrnRegistry records created exclusively by batch_id (cascading cleanly to all child DDI tables, shortcut tables, and DatafileVariableFrequency), removes URNAlias and MetadataQuarantine rows created by the batch, and marks the IngestBatch receipt as ‘undone’.

Pipeline Orchestration

End-to-end ingestion pipeline orchestrator (fairwddi ingest run).

fairwddi.ingest.pipeline.run_ingestion_pipeline(file_path, profile='request', output_dir=None, agency=None, id_strategy='hierarchical', plan_only=False, harmonize=False, force_reload=False, auto_approve=False)[source]

Execute the multi-stage FAIRwDDI ingestion pipeline on a metadata file.

Stages:

  1. Preflight check (and explicit DDI-C -> DDI-L 4.0 upgrade on disk if input is DDI-C).

  2. Direct Ingestion Plan (plan_ingestion) with zero DB writes.

  3. Direct Ingestion Apply (apply_ingestion) into ReQuest core tables + IngestBatch receipt (unless plan_only=True).

  4. Optional comparison & harmonization (when harmonize=True).

Harmonization & Cross-Survey Clustering

Stage 3b (Harmonization & Undo): Review-gated harmonization planning, execution, and rollback.

Supports: - Multilingual label/question text merging (merge_multilingual) - Canonical URN aliasing & cascade pointer consolidation (alias / harmonize) - Semantic relationship linking (link_semantic -> skos:exactMatch / skos:closeMatch) - Full transactional rollback (undo_harmonization) via EventLog snapshots

Absorb one or more study resources into an existing harmonized/elevated resource.

Merges any new multilingual translations, instructions, or extended attributes into the existing target resource, recomputes content hashes, repoints foreign keys and junction tables across the DDI cascade, records canonical aliases in URNAlias, and retires superseded source records.
