Pure Deterministic Import (fairwddi.importer)

The fairwddi.importer package manages format detection, streaming XML/JSON parsing, preflight checks, DDI-C upgrades, deterministic import plans, and atomic batch loading with zero harmonization coupling.

Stage 2 (Pure Deterministic Import & Undo): Streaming metadata load with zero harmonization.

Streams DDI metadata files directly into ReQuest core tables:

  • Strictly pure, deterministic import with ZERO cross-study harmonization, synthetic URNs, or prov:wasDerivedFrom lineage links.

  • Incoming resources are always persisted faithfully with origin='imported'.

  • Same-URN collisions trigger review (reuse on matching hash, quarantine on drift).

  • Faithfully preserves Category.is_missing, CodeItem.is_missing, and CategoryScheme ownership (both single and per_codelist modes).

  • Referential integrity & deletion protection are enforced across undo_import and deletes.

Pure deterministic metadata import orchestrator (fairwddi import <file>).

Executes: 1. Preflight format detection and validation. 2. Optional DDI-Codebook -> DDI-Lifecycle 4.0 upgrade on disk (preserving intra-file

deduplication and selectable CategoryScheme granularity).

  1. Deterministic zero-write import plan (plan_import).

  2. Direct database load (execute_import) unless dry_run=True.

Contains ZERO harmonization or cross-file comparison logic.

fairwddi.importer.pipeline.run_import(file_path, profile='request', output_dir=None, agency=None, id_strategy='hierarchical', harmonize_codes=True, harmonize_questions=True, category_scheme_mode='single', dry_run=False, force_reload=False, auto_approve=False)[source]

Execute the pure deterministic FAIRwDDI import pipeline on a metadata file.

Stages:

  1. Preflight readiness inspection (and explicit DDI-C -> DDI-L 4.0 upgrade on disk when the input file is DDI-Codebook).

  2. Deterministic Import Plan (plan_import) with zero DB writes.

  3. Direct Import Execution (execute_import) into ReQuest core tables + IngestBatch receipt (unless dry_run=True).
