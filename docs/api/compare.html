Independent CodeList & context qualification engine (fairwddi.compare.qualifier).

Implements CDSP ReQuest safeguards: - Isolates missing/sentinel codes (DDI-C =missingvalue, is_missing=True) from

substantive response categories before comparing scales.

  • Evaluates response-domain similarity independently of question/variable wording, flagging scale cardinality mismatches (e.g. 4 vs 5, 5 vs 7) and suspected dimension shifts (e.g. intensity vs frequency, peu vs un peu) so they are never silently merged.

  • Attaches administration-context caveats reminding analysts that routing, filters, and survey mode (PAPI/CAPI/CAWI) sit outside automated wording comparisons.

Level 3 Conceptual & Controlled-Vocabulary Graph Discovery (fairwddi.compare.conceptual).

Performs read-only graph discovery over existing Concept anchors and SKOS/DDI semantic relations (e.g. CESSDA ELSST / SKOS thesaurus hierarchies linked to ConceptualVariable or Category). Defines a forward-compatible ConceptAssigner extension hook while raising NotImplementedError if auto_assign_concepts=True is requested without a registered automated indexer.
