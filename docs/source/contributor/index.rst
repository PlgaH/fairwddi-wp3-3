Contributor Guide
=================

Thank you for your interest in contributing to **FAIRwDDI Lifecycle**!

This guide outlines our development workflow, coding standards, testing practices, and submission guidelines. Following these rules ensures that code quality, type safety, and zero-data-loss database evolution remain consistent across all contributions.
