Apply with fairwddi CLI

Once you have reviewed and saved this approved plan, apply all actions (elevate, absorb, group grids, aliases, merges, semantic links) with:

uv run fairwddi harmonize apply <plan_file.yaml>
Quick CLI Reference:
• uv run fairwddi harmonize elevate -s <src1> -s <src2> -n "Generic Name" — Elevate into canonical bank entity
• uv run fairwddi harmonize absorb -s <src> -i <into_urn> — Absorb wave into existing elevated resource
• uv run fairwddi harmonize approve-high <plan.yaml> -t 0.95 — Triage & auto-approve top-tier matches
• uv run fairwddi harmonize undo <job_id> — Roll back entire transaction via EventLog snapshots
